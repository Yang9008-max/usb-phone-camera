USB 手机摄像头本地版（Windows x64，免安装）

手机接在哪台电脑，就在那台电脑运行本工具，无须原来的电脑。

1. 完整解压这个包。
2. 如果那台电脑之前运行了“局域网接收端”，先双击旧包中的“关闭本地预览.cmd”，避免同一端口被占用。
3. 把手机通过 USB 数据线接到要观看画面的电脑。
4. 若手机还没安装 App，将本包“手机端”文件夹里的 APK 复制到手机 Download 文件夹，在手机上点 APK 安装并允许相机权限。复制时可切换 USB 用途为文件传输；复制完成后在手机设置中开启 USB 网络共享，打开 Android IP Camera 并保持 App 在首页。已安装的手机不必重装。
5. 双击“启动USB摄像头.cmd”。程序自动识别本机 USB 网卡的手机地址，打开 http://127.0.0.1:9890/。

手机 App 设置：TLS Version 选择 TLS Disabled (HTTP only)，关闭 Enable Authentication；端口默认 4444。
若保留认证，请在网页“手机连接设置”中填写用户名与密码，再连接。
本包已带 Node.js，不需要安装 Node、不需要 ADB/USB 调试、不需要原电脑联网或转发。
本包已包含手机端 APK 和手机安装说明；手机摄像头需要该 App，不是仅靠浏览器就能直接读取。
关闭网页不会停止后台接收；双击“关闭USB摄像头.cmd”可停止。
换手机、USB 网卡地址变化或重新插拔后，可重新双击启动，自动更新手机地址。
复制/保存图片发给 AI，或共享纯画面窗口。此包提供网页画面，不安装系统虚拟摄像头。

第二阶段：AI 持续看画面、分析与朗读
1. 首页有手机画面后，点击“AI 持续分析与朗读”，或打开 http://127.0.0.1:9890/ai。
2. 填写 API 地址、模型与密钥。官方默认 https://api.openai.com/v1，模型 gpt-6.1-sol，接口 Responses。
   兼容中转填写服务商的地址与图像模型；仅支持 Chat Completions 的服务选择相应接口。
3. 写下希望它关注的事项，点击“开始持续分析”。每轮自动发送连续采样画面，比较上一轮观察并分析变化。
4. 默认自动朗读结果；可先点击“试听”检查电脑声音，无中文声音时可在 Windows 语言设置安装中文语音。
5. 点击“停止”会取消请求并清除内存中的密钥。关闭页面后约 15 秒停止；已发送请求可能仍产生费用。

gpt-6.1-sol 支持图像输入与文字输出，不支持直接视频或音频输入。
本工具持续发送带时间顺序的画面序列，不需要手动截图；快速动作可能遗漏，不采集麦克风。
默认为 1 帧/秒采样、每轮最短间隔 4 秒。API 慢时跳过积压画面，分析最新片段；预览仍直接通过 USB。
API 调用可能收费；ChatGPT/Codex 登录状态不等于本工具有 API 密钥。
密钥只保存在内存，不写文件、不上传 GitHub；图像发往你选择的 API 服务，不保存录像。
没有密钥也可先预览、试听。此版本用模拟 API 验证流程，真实模型需填入有效 API 密钥后使用。

中转兼容提示（0.2.1）：
若提示“仅允许官方 Codex 客户端”，请服务商开放普通 API 客户端权限；程序不会冒充官方客户端。
若密钥与 Codex 或其他程序共用，会共享用户并发上限。等其他请求结束，或请服务商提高并发再开始。
本版可识别中转返回的 JSON 与流式混合错误，显示真实限制，不直接显示可能包含敏感数据的原始正文。
