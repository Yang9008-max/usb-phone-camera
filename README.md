# USB 手机摄像头：实时预览、AI 持续分析与朗读

把安卓手机通过 USB 接到当前 Windows 电脑，在这台电脑的 `http://127.0.0.1:9890/` 查看手机摄像头画面。手机连接哪台电脑，就在那台电脑运行，不需要另一台电脑转发或公网隧道。

## 下载使用

从本仓库 Releases 下载 `usb-phone-camera-windows-x64.zip`，完整解压。包内已附带 Node.js 和手机端 Android IP Camera APK，无须另找手机安装包或安装开发环境。

1. 将手机通过 USB 数据线接到要使用的 Windows x64 电脑。
2. 首次使用时，打开解压后的 **手机端** 文件夹，将其中的 `androidipcamera-0.14.0-universal-release.apk` 复制到手机 Download 文件夹，在手机文件管理器中点 APK 安装并允许相机权限。复制文件时可将 USB 用途切为文件传输；已安装的手机不需要重新安装。
3. 文件复制完成后，在手机设置中开启 **USB 网络共享**，打开 Android IP Camera。手机也可从本仓库 Release 单独下载 APK 安装。
4. 手机 App 设置：**TLS Version → TLS Disabled (HTTP only)**；关闭 **Enable Authentication**；端口使用默认 **4444**。若保留认证，在电脑网页的“手机连接设置”中填写账号密码。
5. 双击 **启动USB摄像头.cmd**。程序识别本机 USB 网卡的手机网关，打开 `http://127.0.0.1:9890/`。

手机 App 保持在首页，USB 网络共享保持开启。关闭网页后接收程序仍在后台；双击 **关闭USB摄像头.cmd** 可停止接收。

换电脑、换手机或重新插拔后，重新双击启动即可识别当前手机地址。若此前运行其他本地接收工具，请先关闭它，避免占用 9890 端口。程序会提示端口冲突，不会关闭其他程序。

## 功能

- 本机接收手机 MJPEG 视频，保留原始 JPEG，不经过公网中转。
- 预览、纯画面窗口、保存图片、复制图片到剪贴板。
- 断线自动重连；断线后清除旧画面，禁止把旧图当成实时快照导出。
- 仅监听本机 `127.0.0.1`，不需要开启局域网入站共享。
- 不需要 ADB 或 USB 调试。
- AI 连续观察最新画面序列，结合上一轮分析描述动作和变化，流式显示文字。
- 支持官方 Responses API 和兼容中转的 Chat Completions 接口，可指定支持图像的模型。
- 使用 Windows / 浏览器的语音朗读分析结果，无须额外的语音 API 密钥。

可以将图片粘贴或上传到豆包、ChatGPT 等应用，也可以在支持窗口共享的应用中共享纯画面窗口。本工具提供网页画面，不安装系统虚拟摄像头。

## 第二阶段：让 AI 持续看画面

1. 确认首页能看到当前手机的 USB 摄像头画面，点击 **AI 持续分析与朗读**，或打开 `http://127.0.0.1:9890/ai`。
2. 填写 API 基础地址、模型、接口类型和 API 密钥。官方默认地址为 `https://api.openai.com/v1`，模型为 `gpt-6.1-sol`，接口类型为 **Responses**。兼容中转填写该服务商的基础地址；仅支持 `/chat/completions` 的服务选择 **Chat Completions**。中转服务是否支持此模型和多图输入，需要该服务商确认。
3. 填写你希望 AI 关注的事项，例如“观察我正在操作的零件，描述每一步动作”。点击 **开始持续分析**。
4. 左边实时预览，下面逐步显示分析；默认自动朗读完成的分析。可选声音并点击 **试听**。无中文声音时可在 Windows 语言设置安装中文语音；声音是否联网取决于浏览器与所选语音。
5. 点击 **停止** 取消本机正在执行的请求并清除内存中的密钥。重新开始需要重新输入密钥。关闭分析页会请求停止，关闭通知未送达时，约 15 秒内自动停止。

**模型能力与实现方式：** [GPT-6.1 Sol 官方说明](https://developers.openai.com/api/docs/models/gpt-6.1-sol)列出图像输入与文字输出，不支持直接输入视频或输出音频。本功能默认持续采样每秒 1 帧，每轮发送最新约 3 秒内的一组带时间戳图像，最多 6 帧，并提供上一轮观察用于比较。它持续观察视频的变化，不需要人工截图上传；但这不是模型原生完整视频流输入，采样之间的快速动作可能遗漏，也没有采集麦克风。朗读的是模型输出的分析文字。

**延迟与费用：** 默认每轮最短间隔 4 秒，一次只允许一个 API 请求。响应较慢时直接取当前最新片段，不排队分析旧视频。预览延迟和 AI 分析延迟是两回事，界面会显示画面时间、采样帧数和生成耗时。提高采样速度、降低间隔会增加 API 消耗，费用由服务商决定；ChatGPT / Codex 的订阅与登录状态不会自动提供本程序的 API 密钥。停止请求不保证服务商免除已经接收请求的费用。

**数据与密钥：** 开始后，所采样的图像和观察任务会发送给所选 API 服务。密钥只留在本机程序内存中，不写入文件、日志或浏览器存储，也不会返回给页面状态接口。图像缓冲只保留最近片段；程序不保存录像。页面仅显示最近 4 轮分析，后续请求只携带上一轮分析文字，不无限累积图片历史。接口报错会停止循环，以免反复调用。

配置完毕前可以先使用预览和朗读试听。没有 API 密钥时无法得到真实模型分析，不会自动使用当前 Codex 会话的凭据。

升级版本时，请先使用旧安装包的 **关闭USB摄像头.cmd** 停止旧服务，再启动新包，避免浏览器仍连接旧版本。

如果提示“仅允许官方 Codex 客户端”，说明中转账户拒绝普通 API 客户端。需要服务商提供允许普通 Responses / Chat Completions 请求的分组或账户；只改模型名、图片格式或网络连接不会解除此限制。程序不会冒充官方客户端。若 API 密钥与 Codex 或其他程序共用，还会共享用户并发上限，需要结束其他请求或由服务商提高并发。

## 源码运行与打包

电脑安装 Node.js 后，运行 `app/启动USB摄像头.cmd` 前需要将 Node 可执行文件放到 `app/node.exe`。也可以自行启动服务，手机地址使用 USB 网卡的网关：

```powershell
node app/server.js --phone http://手机USB网关:4444
```

重新生成免安装包：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1 -NodeExe "C:\Program Files\nodejs\node.exe"
```

当前发布包采用 Node.js **24.18.0**，构建脚本要求该版本，以匹配随包附带的完整第三方许可证。构建产物位于 `artifacts/usb-phone-camera-windows-x64.zip`。

## 验证与限制

```powershell
npm test
```

测试使用明确标注的模拟 JPEG、模拟手机 MJPEG 服务和模拟 API，验证直接接收、原尺寸截图、独立运行，以及连续帧时序、跨轮观察、慢请求不积压、流式中文、停止中断请求、密钥错误和两类 API 协议。没有真实 API 密钥时不声称已完成真实模型测试。启动/关闭 PowerShell 脚本已通过语法检查；目标电脑的 USB 网卡识别、真实手机画面、服务商权限及实际扬声器朗读仍需在实际设备验证。

0.2.1 排查取得实际中转原始错误：“This account only allows Codex official clients”。该错误以 JSON 前缀附加在流式通用错误前，旧版本只读到了“上游失败”；本版识别 JSON 前缀与 HTTP 错误正文，显示经过映射的具体原因，不直接回显可能包含敏感信息的服务端文字。对混合响应、分块 JSON 和 HTTP 403 的回归测试通过。

真实 USB 画面已在本机验证，约 16–17 帧/秒，Windows 中文语音的实际浏览器朗读事件正常开始并完成。但该中转限制普通 API 客户端，且 API 密钥与 Codex 共用并发，尚未从它取得成功的画面分析结果。服务商解除限制后可重新开始；其他电脑的 USB 硬件与语音仍需在目标设备确认。

需要手机摄像头 App 和 USB 网络共享，并非只靠浏览器就能读取外接手机摄像头。实际延迟由手机采集、USB 传输和显示决定；本机读取已接收图片的耗时不等于完整拍摄延迟。
